## 0. 시연이 보여 줄 것 (한 줄)
> **"처음 광고하는 디저트 사장님이 질문 몇 개로 세팅을 끝내고, 한 달 뒤 결과를 올리면 다음 달에 바꿀 칸을 받는다."**

보여 줄 장면은 세 개입니다: **내 손님 찾기 → 세팅값 시트 → 다음 달 바뀐 칸.** 나머지는 지나가며 보여 줍니다.

## 1. 시연 대본

| 시간 | 화면 | 클릭 | 말할 것 |
|---|---|---|---|
| 0:00~0:15 | 홈 | "예시로 해 보기: 소연베이크" | "1인 구움과자 가게, 하루 주문 2~3건, 한 달 30만 원으로 광고를 처음 해 보려는 사장님입니다." |
| 0:15~0:50 | ① 2/5 내 손님 찾기 (상품 단어와 카드가 이미 채워져 나옴) | 탭 '검색어 묶음' → '손님은 누구?' → '언제 많이 찾나?' | "연관 검색어 1,200개를 목적별로 묶었습니다. 쿠키선물세트를 찾는 사람은 30대 여성이 분야 평균의 1.82배, 9월에 가장 많이 찾습니다. 쿠키 만들기·디저트 맛집은 사러 온 사람이 아니라 제외 검색어로 넣습니다." |
| 0:50~1:10 | ① 3/5 예산·예측 | "다음: 예산·예측" | "네이버는 검색하는 사람만큼만 쓸 수 있어서 상한을 먼저 계산하고, 남는 돈은 메타로 보냅니다. 네이버 하루 5,000원, 메타 하루 10,710원으로 14일. 예상 주문은 13~17건이라 첫 달은 손해일 수 있다는 것까지 그대로 보여 줍니다." |
| 1:10~1:40 | ① 4/5 챗봇 질답 → 5/5 세팅값 시트 | 챗봇 질문에 차례로 답함 (목표 → 기간 → 지역 → 손님 → 상품 장점은 직접 입력해 문구 3개 받기). 시간이 모자라면 마지막 몇 개만 권장 답으로 | "메타 광고 관리자 칸은 47개지만, 챗봇이 사장님께 묻는 건 12개입니다. 대답하는 대로 칸이 채워지고, 나머지는 기본값과 이유를 보여 줍니다. 종료일은 비워 두면 계속 돈이 나가서 챗봇이 꼭 물어봅니다. 다 답하면 광고 관리자에 그대로 옮겨 적을 세팅값 시트가 나옵니다." |
| 1:40~2:20 | ③ 진단 (사이드바) | "예시 계획으로 진단해 보기" → 케이스 C2 · 가상 실제 | "한 달 뒤 결과를 올렸다고 해 보겠습니다. 클릭 단가는 싸 보이지만, 클릭의 28%가 다른 앱 광고 자리에서 나왔고 인스타그램에 쓴 돈은 21%뿐입니다. 싼 클릭이 좋은 클릭은 아닙니다." |
| 2:20~2:40 | ③ 효과 확인 | 아래로 스크롤 | "광고 전후만 비교하면 가게 이름 검색이 +185%지만, 연말 시즌을 빼면 +118%입니다. 광고를 보고 나중에 검색해서 산 주문은 약 12건으로 추정했고, 가상 데이터의 정답은 13건입니다." |
| 2:40~3:00 | 다음 달 세팅 | "다음 달 세팅 만들기" | "진단 결과가 다음 달 세팅의 바뀐 칸으로 넘어옵니다. 노출 위치는 인스타그램 직접 선택으로, 사진은 세로까지. 사장님은 이 두 칸만 고치면 됩니다. 이렇게 매달 세팅 → 진단 → 다시 세팅이 이어집니다." |

**시간이 남으면 (+15초):** ③ 진단으로 돌아가 같은 C2로 한 번 더 "다음 달 세팅 만들기" → "3개월 차예요. 이번 진단에서는 새로 바꿀 칸이 없어요" (같은 결과면 같은 칸을 또 바꾸지 않는다).
**광고 안 함 대조군 (질문이 나오면):** 케이스 C0 → 효과 확인에서 전후 +31%, 시즌을 빼면 +2% ("광고를 안 해도 연말엔 늘어 보인다").
**만원 실험 데이터가 들어오면:** 1:40 장면의 C2를 실제 데이터(`mode=real`, '내 파일 올리기')로 바꾸거나, 2:40 뒤에 "실제로 돌려 보니 CPM은 가정 범위 안 / 밖이었다"를 10초 덧붙임 (T13).

## 2. 실패할 때 쓸 백업

| 무엇이 실패하면 | 대신 |
|---|---|
| 네이버 API·데이터랩 | 배포 앱에는 키가 없어서 처음부터 저장된 캐시로 돎. 실시간 토글은 켜지 않음 |
| LLM (키 없음) | 문구는 문장 틀로 나옴 (지금 배포 앱도 이 상태) |
| 배포 앱 접속 (첫 접속 때 깨우는 데 수십 초) | 발표 직전에 한 번 열어 깨워 두기. 안 되면 로컬 실행 창 |
| 전부 | 시연 영상 (11/30 녹화, T15) |

## 3. 리허설 점검표

- [ ] 발표 직전 배포 앱을 한 번 열어 깨워 두기 (Streamlit Cloud는 오래 안 쓰면 잠듦)
- [ ] "예시로 해 보기" 하나로 처음부터 다음 달 세팅까지 막힘 없이 가는지
- [ ] 각 장면에서 말하는 숫자가 화면 숫자와 같은지 (1.82배·9월, 5,000원·10,710원, 13~17건, 47칸·12개, 28%, 21%, +185% → +118%, 12건·13건)
- [ ] 화면 글자가 발표장 화면에서 읽히는지 (다크 모드면 라이트로 바꿀지)
- [ ] 3분 안에 끝나는지 (리허설 2회 시간 재기)
- [ ] 영상 백업이 발표 PC에서 재생되는지
