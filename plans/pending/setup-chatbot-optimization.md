# 세팅 챗봇 최적화 (MVP 7d)

> 작성 2026-11-09 · 기획 세션 · 상태: **확정 (11/9)**, 개발 요청 대기
> 배경: 프로토타입 세션 논의 노트 `세팅챗봇_최적화_논의.md` (공유 노트 폴더). 코드는 아직 바뀌지 않음.
> 대상: 코치 3단계 '🙋 세팅하다 막히면 물어보세요' (`app/main.py` `setup_helper`), `src/engine/setup_rag.py`, `data/rag/*.md`

## 목표 (재는 방법까지)
페르소나: **네이버·메타로 광고를 처음 내려는 디저트 판매자**가 챗봇과 주고받으며 세팅을 끝낸다.
디저트 전용 챗봇은 아니다. 지금 세팅 챗봇을 매체별 단계 안내로 최적화한다.

- 지금: 디저트 질문 25개 중 맨 위 카드가 맞은 것 **5/25**
- 목표:
  - 맨 위 정답 **23/25 이상** (사용자 결정 11/9)
  - 카드가 없어야 맞는 질문은 '자료에 없어요' 또는 코치 숫자로 답한다
  - 디저트가 아닌 질문 10개(원두·단백질 판매자 말투, 새로 만들어 따로 둠)는 지금보다 나빠지지 않는다. 25문항에만 맞추는 것을 막기 위해서다.

## 원인 → 고칠 곳
| 원인 | 고칠 곳 |
|---|---|
| 조사·어미 조각이 맞음 ("나가게"→'가게', "한테", "하려면") | `tokenize`: 흔한 조사·어미를 떼고 2글자 조각을 만듦, 질문 쪽 불용어 |
| 매체를 말하지 않으면 메타 카드로 쏠림 | 처음에 매체를 고르고, 고른 매체 카드에서만 찾음 (`Index.search(media=)`는 이미 있음) |
| 네이버 카드 빈 곳 5종 | 새 카드 (아래 2단계) |
| "뭐부터 해?", "30만 원 어떻게 나눠?"를 카드로 답하려 함 | 카드 대신 코치 배분(split)으로 답하는 질문 묶음 |
| 한 번 묻고 한 번 답 (진행 위치·대화 기억 없음) | 매체별 단계 안내 (3단계) |

## 단계

### 1단계: 매체 고르기 + 찾기 정확도 (S)
- 다 된 기준:
  - 3단계 맨 위에서 **네이버 / 메타 / 둘 다** 중 하나를 고른다.
  - 기본으로 표시되는 것: "네이버 먼저 세팅하기". '둘 다'를 고르면 네이버부터 하고, 끝나면 메타로 이어진다.
  - 25+10문항 시험이 테스트로 고정되고, 위 목표 중 카드 없이도 되는 몫을 통과한다.
  - "뭐부터 / 어떻게 나눠" 질문은 코치 배분 숫자로 답한다.
- 확인: `.venv/bin/python -m pytest tests/test_setup_rag.py -q` (정확도 출력 포함), 배포 앱 3단계에서 매체를 고르고 칩을 눌러 확인
- 바뀔 파일: `src/engine/setup_rag.py`, `app/main.py`, `tests/test_setup_rag.py`, `tests/fixtures/setup_questions.json`(새 파일)
- 선행: 없음

### 2단계: 네이버 빈 카드 5종 (M)
- 다 된 기준:
  - 카드마다 공식 도움말을 읽고 ✅/△/❓, 출처, 확인일, 화면 단서, 코치 연결을 적는다.
  - README 현황표를 고친다.
  - 25문항 맨 위 정답 23개 이상 통과한다.
- 카드:
  1. 제외 키워드
  2. 광고그룹 지역·요일·시간·PC/모바일
  3. 확장소재
  4. 광고 심사 표현 (최상급·가격 표기, 네이버 광고 검수 기준 공식 페이지)
  5. 대목 전 예산·입찰 미리 올리기 (데이터랩 계절성 + 앱의 `seasonal`과 연결)
- 확인: 같은 pytest + 카드 형식 검사 (`parse_cards` 테스트)
- 바뀔 파일: `data/rag/naver_searchad.md`, `data/rag/README.md`
- 선행: 1단계 (시험 묶음이 있어야 효과를 잼)

### 3단계: 매체별 단계 안내 (M)
- 다 된 기준:
  - 고른 매체의 세팅 순서를 한 단계씩 보여 준다.
    - 네이버: 가입·비즈머니 → 광고 유형 → 광고그룹(지역·시간·기기) → 키워드·제외 키워드 → 소재 → 입찰가 → 전환 추적
    - 메타: 목표 → 예산 → 타깃 → 노출 위치 → 소재 → 픽셀
  - 각 단계에 그 단계 카드와 '내 숫자'를 붙이고, "다 했어요 / 여기서 막혔어요" 버튼을 둔다.
  - '막혔어요'를 누르면 질문칸이 열리고, 그 단계 카드에서 먼저 찾는다.
  - 진행 위치는 세션 안에서만 기억한다.
  - 키가 있으면 앞 대화 6턴을 기억해 이어서 답한다.
  - 키가 없어도 단계 안내와 카드 요약은 그대로 동작한다.
- 확인: 단계 이동·매체 전환 테스트, 배포 앱에서 예시 1·2로 처음부터 끝까지 눌러 보기, UX 체크리스트(`UX_설계원칙.md`)
- 바뀔 파일: `src/engine/guide.py`(메타 단계 목록 추가, 네이버 `naver_checklist`의 card id 재사용), `app/main.py`, `src/engine/setup_rag.py`(대화 기억), 테스트
- 선행: 1단계 (2단계와는 따로 진행 가능. 다만 새 카드 id를 단계에 붙이는 일은 2단계 뒤)

### 3단계에 더하는 것: 광고 세팅값 모으기 (M, 3단계와 한 번에)
목표: 챗봇과 단계를 따라가다 보면 **네이버·메타 광고 관리자에 넣을 광고 세팅값이 모두 마련된다** (사용자 요청 11/9).

- 다 된 기준:
  - 단계마다 버튼이 "다 했어요" 대신 **"이 값으로 할게요"**가 되고, 그 단계의 광고 세팅값이 모인다.
  - 사장님은 값을 고칠 수 있다.
  - 값마다 어디서 나온 값인지 표시한다: 🧮 코치 계산 / 🙋 사장님 답 / ✍️ 초안
  - 끝까지 가면 '광고 세팅값' 시트가 나온다. 매체별로 광고 관리자에서 누르는 순서대로 정리하고, 복사 버튼, 엑셀 내려받기, 계획 파일 저장을 붙인다.
  - **대량 등록 파일이 필요한 곳은 그 단계에서 차례대로 안내한다** (사용자 결정 11/9).
    - 네이버: 화면에서 캠페인·광고그룹 만들기 → 광고그룹 ID 붙여 넣기 → 키워드·소재 대량 등록 파일 내려받기 → 대량 관리에서 올리기
    - 메타: 이미지·영상을 계정에 먼저 올리기 → 일괄 가져오기 파일 내려받기 → 올리고 미리 보기에서 개수 확인
    - 쇼핑검색(상품 연결)처럼 파일로 안 되는 곳은 화면 안내와 세팅값만 준다.
  - 대량 등록 파일의 열 이름은 **팀원 계정에서 받은 빈 양식**에 맞춘다. 양식이 오기 전에는 시트와 엑셀만 낸다.
- 광고 세팅값 목록:
  - 네이버 (쇼핑검색 기본)
    - 🧮 캠페인 유형, 하루 예산, 기본 입찰가(최소 50원부터), 전환 추적 대상, NT 꼬리표 링크
    - 🙋 캠페인·광고그룹 이름, 연결할 상품, 지역·요일·시간·기기
    - '파워링크도 할래요'를 고르면 더한다:
      - 키워드 목록(키워드 도구 결과에서)과 입찰가
      - 제외 키워드
      - ✍️ 제목(15자 이하)·설명(20~45자)
      - 확장소재
  - 메타
    - 🧮 목표(스마트스토어면 트래픽), 하루 예산, 입찰 '최고 볼륨'
    - 노출 위치는 자동, 기여 설정은 기본값
    - 🙋 캠페인·광고 세트·광고 이름, 지역·나이, 이미지 비율
    - ✍️ 기본 문구·제목
    - 연결 URL(UTM)
- 광고 문구: 키가 있으면 AI가 초안 3개를 쓰고, 키가 없으면 대화에서 받은 상품명·강점·혜택으로 틀을 채운다. 어느 쪽이든 글자 수와 심사 표현(최고·최상급·가격 표기, 2단계 심사 카드 기준)을 규칙으로 검사한다.
- 확인: 예시 1·2로 끝까지 가서 시트 값이 코치 숫자와 같은지 확인하는 테스트, 엑셀 내려받기 열기, 글자 수·심사 표현 검사 테스트, 배포 앱 확인
- 바뀔 파일: `src/engine/guide.py` 또는 새 `src/engine/ad_settings.py`, `app/main.py`, 계획 파일 저장부, 테스트
- 선행: 3단계 단계 목록, 2단계 심사 표현 카드. 대량 등록 파일은 **팀원 빈 양식** (사람 일, 받았는지 확인하는 단계 따로 둠)

### 네이버 광고 세팅값 항목: 공식 API 명세 기준 (11/9 확인)
출처: 네이버 검색광고 API 공식 명세 https://naver.github.io/searchad-apidoc/#/tags. 원본 JSON은 `assets/json/ncc-heroes-ncc.json`.
화면과 대량 관리 양식이 결국 이 항목들을 채우는 것이라 광고 세팅값 목록의 기준으로 쓴다. ads.naver.com 화면은 Claude 도구에서 막혀 있어 화면 글자와는 아직 대조하지 않았다.

| 단계 | 항목 (API 이름) | 세팅값으로 줄 것 |
|---|---|---|
| 캠페인 | 유형 `campaignTp` (WEB_SITE=파워링크, SHOPPING=쇼핑검색), 이름, 하루 예산 `dailyBudget`+`useDailyBudget`, 소진 방식 `deliveryMethod` (기본 빠른 소진 / 균등), 전환 추적 `trackingMode`, 기간 | 🧮 유형·하루 예산, 🙋 이름. 소진 방식은 '균등'이 작은 예산에 맞는지 3단계에서 판단 |
| 광고그룹 | 캠페인 ID 필요, 비즈채널 `pcChannelId`/`mobileChannelId`, 기본 입찰가 `bidAmt` (70~100,000원, 비우면 70), 그룹 하루 예산, PC/모바일 입찰 가중치 (10~500%), 타깃 `targets` (요일·시간, 지역, 매체, PC/모바일), 소재 노출 방식 `adRollingType` (번갈아 / 성과 순) | 🧮 입찰가, 🙋 지역·시간·기기 |
| 광고그룹 (파워링크) | **확장 검색 `useExpSearch` 기본 켜짐**, **ADVoost Max `aiAdsOptIn` 기본 켜짐**, 확장 검색에 쓸 예산 비율 (기본 100%) | 작은 예산에서 켜 둘지 끌지 안내 (새로 찾은 것. 카드와 코치 규칙 필요) |
| 타기팅 세부 | 일정(SD)·지역(RL)·반경(RP)·기기(DV)·나이(AG)·성별(GN), 입찰 가중치 50~500%, 노출 제외 | 🙋 디저트 예: 당일배송 지역만, 저녁 시간 가중 |
| 키워드 (파워링크) | 광고그룹 ID 필요, 키워드, 입찰가 70~100,000원 또는 그룹 입찰가 사용 | 키워드 도구 결과 + 🧮 입찰가 |
| 제외 키워드 | 광고그룹의 `restricted-keywords` | 🙋 + 규칙 제안 (예: 레시피, 만들기) |
| 소재 | 유형 `TEXT_45`(단일형), `RSA_AD`(반응형, assets), `SHOPPING_PRODUCT_AD`(쇼핑 상품, 입찰 정보 필요) | ✍️ 제목·설명, 쇼핑은 상품 연결 |
| 확장소재 | 유형 HEADLINE·DESCRIPTION·SUB_LINKS·PRICE_LINKS·PROMOTION 등. 노출 요일·시간과 기간 설정 가능. API로 못 만드는 유형도 있음 (POWER_LINK_IMAGE, SHOPPING_EXTRA 등) | ✍️ 추가 제목·홍보 문구 |

- 광고그룹은 캠페인 ID가, 키워드와 소재는 광고그룹 ID가 있어야 만들어진다. 대량 등록에서 광고그룹 ID가 필요하다는 2차 자료와 맞는다.
- 이 앱은 API로 광고를 만들지 않는다 ('절대' 참조). 명세는 세팅값 항목과 범위를 맞추는 데만 쓴다.

## 용어
- **광고 세팅값**: 네이버·메타 광고 관리자에 사장님이 넣는 값 전부(예산, 입찰가, 목표, 타깃, 키워드, 문구, 링크 등). '광고 입력값'이라고 하지 않는다 (사용자 결정 11/9).
