# 크롬 웹 스토어 비공개(Unlisted) 등록 자료 — Ad assistant 0.1.0

올릴 파일: `store/ad-assistant-0.1.0-chrome.zip` (서버 주소 https://ad-assistant.gem-9ru.com 으로 빌드)
다시 만들기: `cd extension && WXT_API_BASE=https://ad-assistant.gem-9ru.com npx wxt zip` → `.output/*-chrome.zip`

## 1. 스토어 등록정보 (Store listing)

- **이름**: Ad assistant (manifest에서 옴)
- **요약 설명** (manifest, 132자 이하): 처음 하는 메타 광고를 찾기부터 분석까지 도와주는 코치
- **자세한 설명**:

  메타(인스타그램·페이스북) 광고를 처음 하는 1인 가게 사장님을 위한 도우미예요.

  - 시작 전 준비물: 페이스북 계정·페이지·결제 수단·사진이 있는지 먼저 확인하고, 없으면 만드는 방법을 알려 드려요.
  - ① 찾기: 네이버 검색 자료로 내 상품을 찾는 손님의 나이·성별과 많이 찾는 때를 보여 드려요.
  - ② 문구: 고른 좋은 점으로 광고 문구 3개를 써 드려요.
  - ② 세팅: 예산·기간·지역을 쉬운 질문으로 정하고, 광고 관리자에서 캐릭터 '뭉치'가 칸을 하나씩 짚어 대신 채워요. 총예산을 넣고 게시 전에 돈 설정을 다시 확인해요. 게시 버튼은 사장님이 직접 눌러요.
  - ③ 분석: 광고가 끝나면 결과 파일을 올려 다음에 바꿔 볼 칸 1개를 알려 드려요.

  비밀번호·결제 정보는 받지 않아요.

- **카테고리**: 생산성 (Productivity)
- **언어**: 한국어
- **아이콘**: 128×128 → `extension/public/icon/128.png`
- **스크린샷**: 1280×800 또는 640×400, 1~5장 (사장님이 찍기: 준비물 화면, ① 찾기, ② 문구, 광고 관리자 위 뭉치, 분석 페이지)

## 2. 개인정보 보호 (Privacy practices)

- **단일 목적 (Single purpose)**: 메타 광고를 처음 하는 사람이 광고를 만들고 결과를 분석하도록 단계별로 안내하는 것.
- **권한 사유**
  - `sidePanel`: 단계별 안내를 브라우저 옆 패널에 띄우려고.
  - `storage`: 사장님이 고른 답(예산·기간 등)과 진행 단계를 브라우저에 저장해 패널을 닫았다 열어도 이어가려고.
  - `tabs`: 광고 관리자 탭을 열거나 찾아 캐릭터 안내를 보내고, 분석 페이지 탭의 단계를 따라가려고.
  - 호스트 권한 `adsmanager.facebook.com`, `business.facebook.com`: 광고 관리자 화면 위에 캐릭터를 띄우고, 사장님이 정한 값을 칸에 넣어 주려고 (게시는 하지 않음).
- **원격 코드 사용**: 아니요 (모든 코드는 확장 안에 있음).
- **수집하는 데이터**: '웹사이트 콘텐츠'(사장님이 입력한 상품 이름·좋은 점), '사용자 활동' 해당 없음. 판매·광고용 사용 안 함, 신용도 판단 안 함 — 세 가지 확인란 모두 체크.
- **개인정보 처리방침 URL**: https://ad-assistant.gem-9ru.com/privacy

## 3. 배포 (Distribution)

- **공개 여부 (Visibility)**: 비공개 (Unlisted) — 링크를 아는 사람만 설치
- **지역**: 모든 지역 (또는 대한민국만)

## 4. 올리는 순서 (사장님이 직접)

1. https://chrome.google.com/webstore/devconsole 에 구글 계정으로 들어가 개발자 등록 (등록비 5달러, 한 번만).
2. [새 항목] → `store/ad-assistant-0.1.0-chrome.zip` 올리기.
3. 위 1·2·3을 채우고 스크린샷 올리기.
4. [검토를 위해 제출]. 보통 며칠 걸려요. 통과하면 '비공개' 링크가 생겨요.

## 주의

- 확장은 공개 서버(ad-assistant.gem-9ru.com)에 연결돼요. 지금 이 서버는 사장님 컴퓨터의 8001 서버를 Cloudflare 터널로 보여 주는 거라, 컴퓨터를 끄거나 서버·터널 탭을 닫으면 확장의 찾기·문구·분석이 멈춰요. 심사하는 동안과 쓰는 동안 켜 두거나, 늘 켜진 서버로 옮겨야 해요.
- 스토어 확장의 ID는 개발용과 달라요. 서버는 모든 확장 ID를 허용해서 그대로 동작해요.
