# 팀 자료 정리 — 새 방향 시작 전 (2026-11-22)

> 출처: 노션 "BOAZ 2차 프로젝트" 메인 페이지, 회의 내용, 데이터 창고, 개인별 메모짱(희수 · 다정 · 제명)의 최근 페이지.
> 목적: 처음부터 다시 짜기 전에, 팀이 이미 확보한 것과 새 방향에 들어갈 자리를 한눈에 보기.

## 0. 새 방향 한 줄

광고를 처음 하는 소상공인이 **크롬 확장 하나**(사이드 패널 챗봇 + 메타 광고 관리자 위 캐릭터)로
**① 찾기**(네이버로 누가·어떤 말로 찾는지) → **② 세팅**(그 연령·키워드로 문구 작성, 캐릭터가 칸마다 안내) → **③ 분석**(돌린 결과로 문제 · 바꿀 칸 · 예상 수치) → 다시 ②.
광고 집행은 메타만. 결과는 처음엔 파일 올리기.

## 2. 팀원별로 이미 확보한 것

### 희수 — 메타 세팅 칸 설계 · 트래픽 진단
- **광고 관리자 칸을 세 종류로 나눔** ✅: 질문하는 칸 / 기본값 + 설명 칸 / 다음 사이클 칸 → 사장님께 실제로 묻는 질문 **약 11개**.
  - 세부 구분: 기본값+설명, 기본값+안내, 자동 생성(이름·UTM), 사전 점검(페이스북 페이지·픽셀), 챗봇이 작성(문구·제목).
  - 원칙: 메타 기본값을 따르되 무엇을 기본값으로 뒀는지 보여 주고, 한 달 뒤 결과로 검증 → "중립 코치".
- **첫 달은 트래픽 목표** ✅: 판매 목표는 구매 데이터가 있어야 작동하는데 초보는 없음 → 첫 달 트래픽, 구매는 스토어 주문으로 확인, 데이터가 쌓이면 판매 목표로 전환 제안.
- **트래픽 진단 파이프라인 7단계** ✅: 입력 확인 → 전처리(메타+스토어, 4주) → 지표 계산 → 판정(문제/정상/판단 보류) → 케이스 1개 → 바꿀 칸과 값 → 다음 달 비교.
- **진단 규칙 표** ✅ (깔때기 위부터, 처음 걸린 것 하나만):
  소재 피로(CTR 30%↓) · 주간 빈도 3회 초과 · CPM 120%↑ · AN 클릭 20% 초과 · CTR 0.7% 미만 · 링크/전체 클릭 30% 미만 · 랜딩 이탈 · CVR 1.5% 미만(2달 합산) · 판단 보류 · 정상(LTV/CAC 기준).
- **케이스 → 다음 달 세팅** ✅: 예) 소재 피로 → 연령 20~44로 넓히기 → 어드밴티지+ → 예산 20%↓ / AN 쏠림 → 노출 위치 수동 / 소재 약함 → A/B 켜기 / 정상 → 예산 20%↑.
- **검증** ✅: 가상 가게 200회 반복 → 소재 피로·랜딩 이탈 정답 100%, 상세페이지 23.5%(2달 합산 48.5%), 오진 0건.
- **광고 관리자 입력 시험** ✅: 진단이 낸 세팅값을 실제로 넣어 보니 막힌 점 14개(페이스북 페이지 없음 등).

### 다정 — 인지도 분석 · 메타 분석 방법론 · 실측 실험
- **인지도 분석** ✅: 도달 = N × (1 − e^(−노출/N)), 필요 예산 = 도달 × 목표 빈도 × CPM ÷ 1,000.
  광고 관리자 실험(게시 없이 측정)으로 확인: ① 돈을 더 쓸수록 효율이 떨어짐(예산 14배 → 도달 7.5배) ② 타겟을 좁히면 메타가 자동으로 바꾸라고 유도 ③ 메타의 타겟 규모는 부풀려짐 → 모든 숫자에 신뢰 등급(A~D).
- **메타가 주는 데이터 → 가능한 분석 표** ✅ (예상치·일별·노출 위치·세그먼트·A/B·Marketing API별 한계 포함).
- **어드밴티지+를 쓸 때 우리가 줄 방법론 5가지** ✅: 자동이 돈을 쓴 곳 해부 / 자동 vs 수동 비교 / 메타 숫자 3중 검증 / 자동화 적합성(주 25건 기준) / 제안은 "토글 + 수치" 단위로.
- **실측 실험 "오븐로그"** ✅ (팀 광고 계정, 가상 가게 랜딩 페이지 + 메타 픽셀):

  | 11/17~20 | A 자동 노출 위치 | B 피드만(AN 제외) |
  |---|---|---|
  | 지출 / 노출 | ₩5,308 / 837 | ₩5,308 / 985 |
  | 링크 클릭 (CTR) | 13 (1.55%) | 17 (1.73%) |
  | 랜딩 도착 / 오픈 알림 | 10 / 0 | 14 / 1 |

  1차(11/16)에는 A 지출 100%가 AN으로 감 → "자동이면 AN으로 쏠린다" 가설의 근거.
  원본 CSV·정리 엑셀·일별 CSV(1117~1120)가 노션 데이터 창고에 있음.
- **실측 기반 분석 방법론** ✅: 데이터가 작아 "B가 낫다"를 확정할 수 없음 → M1 베이지안 A/B("B가 나을 확률 79%"), M2 축소 추정, M3 톰슨 샘플링, M4 Test & Roll, M5 시뮬레이터 보정, M6 해석 안전장치. 선행 연구(Lewis & Rao 2015, Gordon 외 2019, Feit & Berman 2019, Google 베이지안 MMM 등) 정리.

### 제명 — 네이버 광고 · 개발
- **네이버 광고 종류 정리(2026-11 기준)** ✅. 눈여겨볼 변화:
  - 네이버는 "AI가 알아서 하는 광고(ADVoost)"로 이동 중.
  - **2026-11-05 광고주센터가 "네이버애즈"로 개편, AI 맞춤 추천 · 애즈 어시스턴트 · 첫 광고 가이드 추가** → 우리와 겹치는 기능을 네이버가 직접 냄. 단 네이버 안에서만. 우리는 메타 집행 + 중립 분석이라 차별점은 남음.
- **개발** ✅: v0.4 ~ v2 프로토타입(Streamlit). 네이버 검색광고 API(키워드 도구)·API HUB 데이터랩(연령·성별) 연동, Claude 문구 초안, 진단 엔진, 펫 캐릭터(앱 안).

## 4. 정해야 할 것 ⚠️

1. **13일 안에 어디까지 만드나.** 크롬 확장 + 새 서버를 처음부터 짜는 것은 일정상 가장 큰 위험. 시연 흐름 하나(예: 오븐로그 가게)를 끝까지 매끄럽게 보이는 범위로 줄일지.
2. **"대시보드 시연" 요구.** 크롬 확장 사이드 패널만으로 대시보드 시연이 되는지, 아니면 ③ 분석 결과를 크게 보여 주는 화면(확장 안의 전체 화면 탭 등)을 따로 둘지.
3. **캠페인 목표.** 희수 설계는 첫 달 **트래픽**, 다정 분석에는 **인지도** 계산기도 있음. 새 흐름에서 인지도를 고르는 길을 남길지, 트래픽 하나로 갈지.
4. **구매 측정.** 스마트스토어엔 메타 픽셀이 없음 → 구매는 스토어 주문 데이터로 본다는 것이 희수·다정 공통 결론. ③ 분석의 입력을 "메타 결과 파일만"으로 할지, "+ 스토어 주문 파일(선택)"로 할지.
5. **예상 수치를 어떻게 말하나.** 실측이 작아 한 숫자로 단정하면 틀리기 쉬움(다정 M1·M6). "클릭당 비용 약 ○○~○○원, 좋아질 확률 ○%"처럼 범위·확률로 말하는 것을 원칙으로 할지.
6. **팀 역할.** 위 매핑대로라면 희수 = ② 질문·③ 진단 규칙, 다정 = ③ 통계·발표 분석, 제명 = 개발(확장·서버)·① 네이버. 팀원들과 맞춰 봐야 함.
