# ② 사전 점검: 스마트스토어 상품 등록 체크리스트 (짧은 설계)

작성 2026-11-26 · 크기: 작은 변경

## 왜
처음 광고를 내는 사장님 중에는 스마트스토어가 없거나 상품을 아직 올리지 않은 분이 많다. 그러면 ② 세팅의 '광고를 누르면 어디로 가요?'에서 붙여 넣을 상품 페이지 주소가 없다.
**목표는 광고에 넣을 상품 페이지 주소 하나를 갖추는 것**이다. 패널은 할 일 체크리스트와 네이버 링크만 준다.

- 하는 것: 해야 할 일 목록(체크박스) + 각 줄의 네이버 링크 + 상품명에 넣을 검색어 한 줄
- 안 하는 것: 상품명·상세 페이지·사진을 대신 써 주기, 스마트스토어센터 화면 위 3D 안내
- 실패로 보는 것: 스토어가 없다고 광고 흐름이 막혀 버리는 것 → "나중에"를 고르면 인스타그램 프로필로 광고를 낼 수 있어야 한다

## 고려한 방법
| 방법 | 장점 | 단점 |
|---|---|---|
| **A. ② 사전 점검에 질문 추가 (고름)** | 스토어 개설은 심사로 하루 넘게 걸릴 수 있어서 가장 앞에서 알려야 미리 시작할 수 있다. 기존 `help` 방식을 넓히면 된다 | 이미 스토어가 있는 사장님도 질문 하나를 더 답한다 (한 번 누르면 끝) |
| B. '클릭 주소' 질문 안에 '아직 없어요' 넣기 | 필요한 순간에만 보인다 | 질문을 한참 답한 뒤에야 알게 되고, 개설이 며칠 걸리면 거기서 끊긴다 |
| C. ②와 세팅 사이에 단계 따로 | 넓게 안내할 수 있다 | 목표보다 크다. `flow.ts` 단계와 위쪽 단계 표시까지 바꿔야 한다 |

사용자가 A와 검색어 한 줄을 골랐다.

## 화면 (부품 이름)
사전 점검의 인스타그램 계정 질문 다음에 묻는다.

```
[코치] 이 상품을 스마트스토어에 올리셨어요?
       광고를 누른 손님이 바로 살 수 있게 상품 페이지 주소가 있어야 해요.
  ( 올렸어요  · 권장 )
  ( 아직이에요 )
```
"아직이에요" → 같은 자리에 카드 (체크리스트, 남은 일 표시):
```
 스토어를 열고 상품을 올려 주세요. 다 하면 '다 했어요'를 눌러 주세요.   1 / 3
 ☑ 판매자 가입 (스토어 이름도 이때 정해요)       [가입하기 ↗]
 ☐ 상품 등록                                    [상품 등록하기 ↗]
    상품명에 이 말을 넣으면 네이버에서 잘 찾아져요: 수제 쿠키 · 선물 쿠키 · 답례품
 ☐ 올린 상품 페이지를 열어 주소 복사하기
 [ 다 했어요 ]                         (주 버튼)
 ← 다시 고르기                  나중에 할게요
```
- 체크박스는 사장님이 직접 누르는 할 일 표시다 (점검표 1번: 할 일 = 체크박스). 다 체크하지 않아도 [다 했어요]를 누를 수 있다.
- 링크는 새 탭으로 열린다.

**주소는 이 자리에서 받는다** (사용자 제안). 답에 따라 같은 카드 안에 주소 칸 하나가 이어서 나온다 (기존 `then_ask`처럼):
- '올렸어요' 또는 [다 했어요] → "올린 상품 페이지 주소를 붙여 넣어 주세요." → `meta.ad.website_url`에 저장, 답 '올렸어요'.
- [나중에 할게요] → "그동안은 인스타그램 프로필로 보낼게요. 주소가 맞는지 확인해 주세요." (인스타 계정으로 미리 채움) → `meta.ad.website_url`에 저장, 답 '아직이에요'.
- 주소 칸 아래 인라인 오류는 지금 쓰는 문구와 같다 (어떻게 고치는지).

뒤의 '클릭 주소' 질문은 그대로 묻되, 받은 주소에 맞는 답이 '권장'이고 주소 칸이 미리 채워져 있어 [다음]만 누르면 된다.
- '아직이에요'였으면 **인스타그램 프로필**이 권장이 되고, 아래에 "스토어가 준비되면 스토어 상품 페이지로 바꿀 수 있어요." 한 줄이 붙는다. 다크패턴이 없도록 두 답은 같은 무게로 보인다.
- 여기서 스토어를 다시 고르면 빈 상품 주소 칸이 나온다 (인스타 주소를 상품 주소로 잘못 넣지 않게).

## 정한 것 (만드는 사람의 판단, 사용자 확인 필요)
1. 질문 id `meta.pre.store_product`, kind `precheck`, 선택지 `[올렸어요, 아직이에요]`, 기본값 `올렸어요`. 광고 관리자 칸이 아니라서 세팅 목록에는 넣지 않는다.
2. 이 질문에 `then_ask`(필드 `meta.ad.website_url`)를 붙이고, `help`의 [다 했어요]·[나중에]도 그 주소 칸으로 이어지게 한다. 나중에 쪽은 `prefill`로 `https://www.instagram.com/{meta.pre.ig_account}`.
   `help`의 답별 항목에 `steps`(목록)를 더한다. 각 줄은 `text`, 선택 `link`·`url`, 선택 `hint: keywords`. `steps`가 있으면 링크 하나 대신 체크리스트를 그린다. 기존 페이스북 페이지 `help`는 그대로 동작한다.
3. 검색어 줄은 ①에서 확정한 검색어(`state.keywords`) 앞 3개다. 검색어가 없으면 줄을 숨긴다.
4. 체크 상태는 패널을 닫았다 열어도 남게 흐름 상태에 저장한다 (스토어 심사로 며칠 걸릴 수 있어서).
5. '클릭 주소' 질문의 기본값은 스펙의 `default_if`로 바꾼다:
   `default_if: {meta.pre.store_product: {아직이에요: 인스타그램 프로필}}` + `note_if`로 한 줄 안내.
6. 링크 주소: 판매자 가입 `https://sell.smartstore.naver.com/#/join`, 상품 등록 `https://sell.smartstore.naver.com/#/products/create` (만들 때 열리는지 확인).

## 확인
- 서버: 새 질문이 `/fields`에 `help.steps`·`default_if`와 함께 나간다 (pytest, `COACH_OFFLINE=1` 포함).
- 패널: '아직이에요' → 체크리스트·검색어 줄·1/3 표시, [다 했어요] → '올렸어요', [나중에] → 클릭 주소 권장이 인스타그램 프로필 (vitest).
- `tsc`, 토큰 검사(`validate-tokens.cjs`), `WXT_API_BASE=http://localhost:8001 npm run build`, 8001 서버 재시작.
