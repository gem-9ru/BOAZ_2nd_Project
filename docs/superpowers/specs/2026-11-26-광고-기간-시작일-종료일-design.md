# ② 세팅: 광고 기간 — 시작일·종료일 직접 정하기 (짧은 설계)

작성 2026-11-26 · 크기: 작은 변경 (광고 관리자 자동 입력 한 칸 추가 포함)

## 왜
지금 '광고를 얼마 동안 하실 건가요?'는 7일·14일·30일만 고를 수 있고, 시작은 게시한 날로 정해진다.
사장님이 기간을 직접 정하거나 다음 주 월요일부터처럼 **시작을 미뤄 예약**할 수 있게 한다 (사용자가 B안을 고름).

- 하는 것: 7일·14일·30일은 그대로 두고 [날짜 직접 정하기]를 더함 → 시작일·종료일 날짜 칸 2개. 광고 관리자의 시작 날짜 칸도 뭉치가 대신 넣음
- 안 하는 것: 요일·시간대 예약 (총예산일 때만 되는 메타 기능)
- 실패로 보는 것: 시작일 자동 입력이 안 됐는데 조용히 넘어가는 것 → 못 넣으면 사장님께 넘김(기존 '사장님 차례' 방식)

## 고려한 방법
| 방법 | 장점 | 단점 |
|---|---|---|
| A. 종료일만 직접 고르기 | 광고 관리자 안내를 바꾸지 않음 | 시작을 미룰 수 없음 |
| **B. 시작일·종료일 둘 다 (고름)** | 예약 광고까지 됨 | 광고 관리자 시작 날짜 자동 입력을 새로 만들고 실제 화면에서 확인해야 함 |

## 화면 (부품 이름)
```
[코치] 광고를 언제부터 언제까지 할까요?
  ( 7일 )  ( 14일 · 권장 )  ( 30일 )      ← 오늘부터
  ( 날짜 직접 정하기 )
```
[날짜 직접 정하기] → 같은 자리에 날짜 칸(`input type="date"`) 2개
```
 시작일 [2026-12-01]   종료일 [2026-12-14]
 12월 1일부터 14일 동안 광고해요.
 [ 다음 ]
 ← 다시 고르기
```
- 시작일 기본값은 오늘. 인라인 오류(칸 바로 아래, 고치는 법): 시작일이 오늘보다 앞이면 "오늘이나 그 뒤 날짜로 골라 주세요.", 종료일이 시작일보다 앞이거나 같으면 "종료일을 시작일 다음 날 이후로 골라 주세요."

## 정한 것 (만드는 사람의 판단)
1. 답 값: 칩은 지금처럼 `7일` 등, 직접 정하면 `2026-12-01~2026-12-14`. `scheduleFrom(answer, today) → { start, end }` 하나로 바꿈 (`endDateFrom` 대체).
2. 세팅 목록에 `meta.adset.start_date`(시작 날짜)를 종료 날짜 앞에 더함 → 13칸 → 14칸. 흐름 상태에 `startDate` 추가.
3. 광고 관리자 안내(`guide/meta_traffic.json`)에 시작 날짜 칸을 종료 날짜 앞에 더함, 자동 방식 `startDate`:
   시작일이 오늘(또는 지난 날)이면 아무것도 하지 않고 넘어감 (지금과 같음). 미래면 '종료 날짜 설정' 스위치 **앞의** 마지막 `yyyy-mm-dd` 칸에 넣고, 정말 바뀌었는지 확인. 못 하면 사장님 차례: "시작 날짜를 {value}로 바꿔 주세요".
4. 종료 날짜 알림(총예산 ≥ 하루 최소 × 기간)의 기간은 **시작일~종료일**로 셈.
5. 대기 화면: 시작일이 미래면 "광고는 12월 1일에 시작해요." 한 줄을 더함. 결과 보러 올 날은 지금처럼 종료일 다음 날.

## 확인
- 테스트: `scheduleFrom`, 직접 정하기 오류 2가지, 세팅 14칸, `setStartDate`(오늘이면 손대지 않음 / 미래면 앞 칸에 넣음 / 못 찾으면 false), 대기 화면 문구.
- **실제 광고 관리자 확인 필요**: 시작 날짜 칸은 값이 `2026년 11월 25일`처럼 보이는데, `yyyy-mm-dd`로 넣었을 때 받아 주는지 사용자 계정(게시 금지)에서 직접 봐야 함. 확인 전까지는 '확인 안 됨'으로 보고.
- pytest(`COACH_OFFLINE=1` 포함), vitest, tsc, 토큰 검사, 빌드, 8001 재시작.

## 덧붙임: 스마트스토어 상품 페이지가 없을 때 (같은 날 사용자 요청)
스마트스토어에 올리지 않는 상품도 있으니, 상품 페이지 주소가 없으면 인스타그램 프로필로 보낸다.
- 사전 점검 질문에 세 번째 답 **'스마트스토어에서 안 팔아요'** → 그 자리에서 인스타그램 프로필 주소(계정으로 미리 채움)를 받음.
- 상품 페이지 주소 칸(사전 점검·클릭 주소 두 곳) 아래에 **'상품 페이지 주소가 없어요 → 인스타그램 프로필로 보낼게요'** → 누르면 인스타그램 프로필 주소 칸으로 바뀜 (스펙 `then_ask.none`).
- 클릭 주소 질문: 이 답이면 인스타그램 프로필이 권장, 안내 "스마트스토어 상품이 없으니 인스타그램 프로필로 보내요. 프로필에 상품 사진과 문의 방법을 올려 두세요."

## 덧붙임: 시작·종료 시각 (같은 날 사용자 요청)
- 날짜 칸 옆에 `input type="time"` 시작 시각·종료 시각 (선택). 비워 두면 광고 관리자 시각 그대로. 답 `2026-12-01 09:00~2026-12-14 21:30`.
- 오늘 시작에 지금보다 앞선 시각이면 인라인 오류 "오늘 시작하면 지금보다 뒤 시각으로 골라 주세요."
- 세팅 값 `2026-12-01 09:00`. 뭉치는 날짜 칸 바로 뒤의 '시간'(0~23)·'분'(0~59) 스핀 버튼에 넣고 값이 됐는지 확인 (2026-11-26 실제 수정 화면에서 구조 확인). 못 하면 사장님께.
- 실제 화면 확인: 이미 시작한 세트의 시작 날짜 칸은 잠겨 있음 → 사장님께 넘김. 새 세트에서 입력이 먹는지는 아직 확인 전.
