# 광고 코치 v3 (크롬 확장) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 오븐로그 가게 하나로 ① 찾기 → ② 세팅(광고 관리자 위 캐릭터 안내) → ③ 분석 → 바꿀 칸 다시 안내가 실제로 끝까지 동작하는 크롬 확장 + 파이썬 서버를 12/5 시연 전까지 만든다.

**Architecture:** 파이썬 서버(FastAPI)가 v2의 순수 파이썬 엔진(네이버 조회·문구·결과 읽기·진단)을 복사해 HTTP로 내놓고, 불확실성 계산(베타 사후분포)과 예상 범위를 새로 더한다. 크롬 확장(WXT + React)은 사이드 패널의 단계 상태 기계가 서버를 부르고, 콘텐츠 스크립트가 안내 목록(JSON)대로 메타 광고 관리자 위에 캐릭터를 띄운다. 보고서 탭이 발표용 대시보드다.

**Tech Stack:** Python 3.9 호환 · FastAPI · uvicorn · pandas · numpy · pyyaml · anthropic · pytest / Node 22(mise) · WXT · React 18 · TypeScript · Tailwind · Recharts · Vitest · @testing-library/react · jsdom

**Spec:** `docs/superpowers/specs/2026-11-22-광고코치-크롬확장-design.md`

## Global Constraints

- 서버 코드는 **Python 3.9 호환** (`match`, `X | Y`, `list[int]` 문법 금지). 이 컴퓨터에는 3.9만 있어서 설계서의 "3.12"를 3.9 호환으로 바꾼다 (3.12에서도 그대로 돈다).
- API 키(`NAVER_AD_*`, `NAVER_HUB_*`, `ANTHROPIC_API_KEY`)는 서버 루트 `.env`(=프로젝트 루트 `.env`)와 환경 변수에서만 읽는다. 확장에 넣지 않고, 응답·로그·예외 문구에 넣지 않는다.
- 서버 주소는 `http://localhost:8000` 고정 (확장 `host_permissions`에 포함).
- 화면 문구는 한국어, `UX_설계원칙.md`와 그 체크리스트를 따른다. 전문 용어는 쉬운 말 + 괄호.
- 사장님께 묻는 질문 칸은 `meta_fields.yaml`의 `kind: question`·`precheck` 11개를 넘지 않는다.
- 예상 수치는 항상 **범위 + 좋아질 확률 + 근거 등급(checked/hypothesis)** 으로만 보여 준다. 한 숫자로 단정하지 않는다.
- 캐릭터는 게시 버튼을 짚기만 하고 **절대 클릭하지 않는다.** 확장은 광고 관리자 칸에 값을 직접 입력하지 않는다(사장님이 입력, 확장은 복사 버튼만).
- 안내 목록의 `find`에 난독화된 클래스 이름(`.x1abc` 등 `.`으로 시작하는 선택자)을 쓰지 않는다. 광고 관리자 화면 언어는 한국어 고정.
- v1(`app/`, `src/`, `tests/`)과 v2(`v2/`) 코드는 수정하지 않는다. 새 코드는 `server/`, `extension/`에만.
- 비목표(구현 금지): 네이버 광고 세팅, 트래픽 외 목표, Marketing API/OAuth, 스토어 주문 연동, 웹스토어 등록, 로그인.

2. **엉뚱한 파일 올리기** (메타 내보내기가 아님, 필수 열 없음, 맨 아래 '합계' 행, 빈 파일) → `/analyze`가 400과 쉬운 한국어 문장("○○ 열이 없어요. 광고 관리자에서 일·노출 위치 기준으로 내보내 주세요")을 준다. (Task 6 테스트)
3. **서버가 꺼져 있음** → 사이드 패널이 "도우미 서버에 연결할 수 없어요 · 다시 시도" 를 보여 주고 대화 상태는 그대로 남는다. (Task 9 테스트)
4. **광고 관리자에서 칸을 못 찾음** (화면 언어 영어, 메타가 화면 구조를 바꿈, 다른 화면에 있음) → 캐릭터가 구석으로 가서 스크린샷 대체 안내 + "했어요" 버튼을 보여 주고, 영어 화면이면 "화면 언어를 한국어로 바꿔 주세요"를 먼저 말한다. 멈추지 않는다. (Task 12 테스트)
5. **안내 도중 사이드 패널을 닫았다 열거나 브라우저를 다시 켬** → `chrome.storage.local`에서 단계와 안내 진행 위치를 복원해 그 자리부터 이어 간다. (Task 8 테스트)

def test_ovenlog_ctr_prob_b_better():
