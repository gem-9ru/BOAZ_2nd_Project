Ad assistant 개인정보 처리방침

Ad assistant(광고 어시스턴트)는 메타(인스타그램·페이스북) 광고를 처음 하는 사장님이 상품 찾기, 광고 문구, 광고 관리자 세팅, 결과 분석을 할 수 있게 돕는 크롬 확장 프로그램이에요. 이 글은 확장 프로그램이 어떤 정보를 어디에 쓰는지 알려 드려요.

받지 않는 정보

  • 비밀번호, 카드·계좌 같은 결제 정보, 신분증 번호는 받지 않고 어디에도 넣지 않아요. 페이스북 로그인과 결제 수단 등록은 사장님이 직접 해요.
  • 광고를 게시하는 버튼은 누르지 않아요. 게시는 사장님이 직접 해요.

쓰는 정보와 쓰는 곳

  • 사장님이 입력한 상품 이름·좋은 점·고른 검색어: 우리 서버로 보내 네이버 검색광고·데이터랩 자료를 찾고, 광고 문구를 쓰기 위해 Anthropic(Claude)에 보내요. 네이버의 숫자 자료는 Claude에 보내지 않아요.
  • ② 세팅에서 고른 답(예산·기간·지역·연령 등): 사장님 브라우저(크롬 저장소)에 저장해요. 분석 페이지로 넘길 때만 서버에 잠시 보관해요.
  • 광고 관리자 화면: 뭉치가 칸을 찾고 값을 넣으려고 사장님 브라우저 안에서만 화면을 읽어요. 화면 내용을 서버로 보내지 않아요.
  • 분석 페이지에 올린 광고 결과 파일: 우리 서버에서 분석하고, 결과는 4자리 코드로 서버 메모리에 잠시(최근 200개까지) 두어요. 파일로 따로 저장하지 않아요. 결과를 설명해 달라고 질문하면 그 결과와 질문을 Anthropic(Claude)에 보내요.
  • 서버 기록: 문제를 찾으려고 요청 시각, 상품 이름, 처리 결과를 서버 기록에 남겨요. API 키나 결제 정보는 남기지 않아요.

팔거나 넘기지 않아요

모은 정보를 팔지 않고, 광고·마케팅에 쓰지 않으며, 위에 적은 곳(네이버 API, Anthropic) 말고 다른 곳에 넘기지 않아요.

지우기

사이드 패널의 [처음부터]를 누르거나 확장 프로그램을 지우면 브라우저에 저장된 답이 지워져요. 서버 메모리의 분석 결과는 서버가 다시 켜지면 사라져요.
