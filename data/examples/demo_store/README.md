# 시연용 가상 데이터: 스마트스토어 예시 2개 (2026-08 ~ 2026-10, 10월 한 달만 광고)

**모두 가짜 데이터입니다.** 실제 가게·주문·사람과 관계없고, 개인정보 항목(이름·연락처·주소)은 처음부터 만들지 않습니다.
다시 만들기: `.venv/bin/python data/examples/demo_store/make_demo.py` (시드 고정이라 늘 같은 파일).

## 만든 방법 (가정)
- 재구매: 두 예시 모두 코치의 '매달(정기)' 프리셋(1년 6번)에 맞춰, 산 적 있는 손님이 하루 6/365 확률로 다시 삼
- 광고 없이 들어오는 새 손님: 원두 하루 1.2명, 단백질 하루 0.6명 (포아송)
- 10월 광고: 코치 배분 그대로 (원두 네이버 6.8만·메타 14.2만, 단백질 네이버 12.1만·메타 37.9만), 클릭 1번 약 1,300~1,900원
- 광고로 누른 사람 중 산 비율: 원두 1.5%(코치 가정 1.26% 수준), 단백질 5%(가정보다 좋은 경우를 보여 주려고 일부러 높게).
  한 달 광고 주문 수와 리포트 전환 수는 '클릭 × 비율'을 반올림한 고정값이고, 날짜만 무작위로 나눔 (시연 숫자가 늘 같은 이야기를 하게)
- 메타 '결과'는 자기 광고 주문 1건마다 원두 0.7건·단백질 0.6건을 더 셈(조회 후 구매·다른 경로 구매) → 과대 집계율 +30~100% 범위로 시연
- 광고 손님 중 쿠폰 사용: 원두 60%, 단백질 90% (쿠폰 = 코치가 가장 믿는 판매 수 출처)

## 예시 2를 고른 근거 (왜 남는가)
코치의 다른 가정(누른 사람 중 사는 비율 1.26%, 메타 클릭 1,300원, 재구매 곡선 모양)은 원두와 똑같이 두고 **판매가·마진·재구매·검색어만** 바꿨습니다.
이 가정이면 광고로 손님 1명을 데려오는 데 약 12~13만 원이 듭니다(클릭 약 1,350원 ÷ 1.1%). 원두는 손님 1명이 1년 동안 남기는 돈이
7천 원 × (1 + 6) = 약 4.9만 원이라 비용의 절반에도 못 미칩니다. 단백질 쉐이크(한 달분 7.9만 원, 마진 50%)는 3.95만 원 × (1 + 6) = 약 27.7만 원으로
비용의 2배가 넘어서, 숫자를 등급만큼 흔들어도 100번 중 약 85번은 남습니다. 1인 브랜드가 OEM으로 만드는 고단가 정기 소모품이라 마진 50%와
매달 재구매가 그럴듯한 범주로 골랐습니다. 같은 조건에서 판매가 5.9만 원이면 72번, 6.9만 원이면 80번이라 7.9만 원으로 여유를 뒀습니다.

## 시연 순서
1. 첫 화면 → 예시 버튼으로 광고 전 답 보기, 또는 "계획 파일 불러오기"에 `plan.json`
2. 한 달 뒤 단계: 쓴 돈·클릭·쿠폰 판매 수에 `summary.json`의 spend·clicks·coupon_orders, 판매처 통계 파일에 `store_stats.csv`
3. "광고 리포트로 다시 계산하기"에 `naver_report.csv`, `meta_report.csv` → 실제 주문 수에 `summary.json`의 ad_orders
