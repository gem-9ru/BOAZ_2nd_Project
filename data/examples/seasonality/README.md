# 예시 계절 지수

배포 앱(네이버 API HUB 키 없음)에서 예시 검색어의 계절성을 보여 주는 파일입니다.
형식: `month`(1~12), `index`(그달 검색량 ÷ 평소, 평균 1). 엔진은 `naver_hub.seasonality_safe`가 실시간 → 저장된 응답 → 이 폴더 순으로 찾습니다.

- 출처: 네이버 데이터랩 검색어 트렌드 (NAVER API HUB), 2026-11-06 조회, 최근 3년 월간 데이터
- 원본 응답이 아니라 가공한 지수만 둡니다: **꽉 찬 12개월이 있는 해만**(2023-11~2026-10 응답이면 2024·2025년) 해마다 평균 1로 맞춘 뒤 같은 달끼리 평균, 다시 평균 1로 맞춤 (2026-11-10 다시 만듦, 검수 A1: 몇 달뿐인 첫해·끝해를 그 해 평균으로 나누면 그 달들이 눌림)
- 파일: `원두커피.csv`(코치 예시 1), `프로틴쉐이크.csv`(코치 예시 2, 2026-11-09 조회), `필라테스.csv`(다음 단계 탭 예시 검색어)
- 화면에는 출처 "네이버 데이터랩 (검색어 트렌드, 예시 지수 파일)"을 표시합니다
