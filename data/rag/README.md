# 세팅 챗봇 RAG 자료 (세팅 카드)

광고 관리자 첫 세팅을 돕는 챗봇이 **찾아보고 근거로 쓰는 자료**입니다.
챗봇은 질문(그리고 사장님이 올린 화면 캡처)에 맞는 카드 3~5개를 키워드 검색(BM25)으로 고르고, 코치 숫자와 함께 답하며 카드의 출처를 붙입니다. 카드에 없는 내용이면 "자료에 없어요"라고 답합니다.

| 파일 | 내용 |
|---|---|
| `naver_searchad.md` | 네이버 검색광고: 키워드 도구(화면·API 명세), 첫 세팅(캠페인 → 광고그룹 → 키워드·소재, 입찰가, 하루 예산, 전환 추적) |
| `meta_ads.md` | 메타 광고: 캠페인 목표, 캠페인 → 광고 세트 → 광고 구조, 예산, 타깃, 게재 위치, 학습 단계, 픽셀·전환 API, 기여 설정 |

## 카드 형식 (모든 카드 공통)

```markdown
## [naver-kw-001] 카드 제목 (사장님 말로)
- 매체: 네이버 검색광고 | 단계: 키워드 고르기
- 질문 예시: "키워드 검색량 어떻게 봐?" / "월간 검색수가 뭐야?"
- 화면 단서: 광고시스템 > 도구 > 키워드 도구, '월간검색수' 열
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://… (공식 문서 주소, 여러 개면 ; 로 구분)
- 코치 연결: 키워드 도구의 월간 검색수 → 코치 Q1 네이버 배분의 수요 상한

본문: 3~6문장. 우리 말로 요약하고, 사장님이 지금 무엇을 누르고 넣을지까지 씁니다.
```

## 규칙
- **확인 표시**: ✅ 공식 문서에서 직접 확인 / △ 공식 문서에서 찾지 못해 다른 자료 기준(출처에 그 자료를 적음) / ❓ 확인 못 함(챗봇이 단정하지 않게).
- **저작권**: 원문을 옮겨 적지 않고 요약합니다. 꼭 필요한 직접 인용은 카드당 15단어 이하 1곳까지, 따옴표로.
- **화면 단서**: 메뉴·버튼·열 이름은 화면에 보이는 글자 그대로 적습니다(스크린샷 읽기와 맞추기 위해). 화면이 바뀔 수 있으니 확인일을 꼭 적습니다.
- **개인정보·키**: 카드에 계정 정보, API 키, 실제 광고 계정 숫자를 넣지 않습니다.
- **코치 연결**: 카드가 코치의 어떤 숫자(네이버·메타 배분, 하루 예산, 검색어, 판매가, 100번 중 ○번)와 이어지는지 적습니다. 없으면 "없음".

## 공식 문서와 지금 앱이 다른 곳 (세팅 챗봇 구현 때 함께 고칠 것)

**네이버** (`src/engine/naver_source.py`, `src/engine/guide.py`)
1. `/estimate/performance`에 보내는 `keywordplus` 값은 2024년에 없어진 항목이라 효과가 없음 (API 공지 2024-07-16).
2. 경쟁정도 `compIdx`는 명세상 low/mid/high인데 실제 응답은 낮음/중간/높음. "< 10" 표기도 명세와 띄어쓰기가 다름. 지금 코드는 둘 다 처리함.
3. 가이드의 입찰가 추정은 파워링크 기준인데, 체크리스트는 스마트스토어에 쇼핑검색(쇼핑몰 상품형)을 권함. 쇼핑검색은 키워드를 넣지 않고 최소 입찰가 50원(가이드는 70원).
4. "노출 순위 = 입찰가 × 품질지수"는 공식 표현이 아님. 연관도·입찰가·광고 품질을 함께 봄. 파워링크는 '광고 연관지수'·'클릭 기대지수'(1~10)로 바뀜.
5. 전환 추적은 도구 > 전환 추적 관리에서 신청해야 하고(스마트스토어는 즉시), 캠페인 설정에서 그 대상을 골라야 함.
6. 판매자용 신규 상품(ADVoost 쇼핑, 스마트스토어 광고)이 체크리스트에 없음.

**메타** (`src/engine/guide.py`, `src/engine/acquisition.py`)
1. 화면 용어는 '학습 단계'가 아니라 '머신 러닝 단계', '학습 제한'이 아니라 '제한된 머신 러닝'.
2. 기준은 광고 세트당 마지막 큰 수정 뒤 7일 안에 결과 약 50개 → 지금 주 50건 가정과 맞음(△ → ✅ 가능). 샵 광고는 기준이 다름.
3. 공식 예산 권장: 하루 예산 ≥ 목표 평균 비용의 10배(결과당 비용 목표 사용 시 5배). 지금 앱의 "주 50 × CPA"와 다른 규칙.
4. 입찰 전략 이름 '최저 비용' → 지금은 '최고 볼륨'.
5. 하루 예산은 어떤 날 최대 75%까지 더 쓰일 수 있음(주 단위로는 7배 상한).
6. 판매·잠재 고객·앱 홍보 목표에서는 수동 게재 위치 선택이 단계적으로 없어지는 중.
7. 기본 기여 설정은 클릭 후 7일·조회 후 1일에 **참여한 조회 후 1일**이 더해짐.
8. 스마트스토어 픽셀: 공식 문서에 언급 없음. 소유하지 않은 사이트에 픽셀 설치 금지, 파트너 목록에 스마트스토어 없음 → ❓ (대행사들은 불가라고 안내). 그래서 "판매" 목표·장바구니 대체도 스마트스토어에서는 어려울 수 있음.
9. 목표 이름이 도움말 표에서는 '매출', 본문에서는 '판매'로 섞여 있음.
