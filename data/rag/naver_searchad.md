## [naver-kw-001] 키워드 도구는 어디 있고 어떻게 검색해요?
- 매체: 네이버 검색광고 | 단계: 키워드 고르기
- 질문 예시: "키워드 도구 어디 있어?" / "검색량 보려면 뭐 눌러?" / "키워드 여러 개 한 번에 볼 수 있어?"
- 화면 단서: 네이버애즈 > 검색광고 > 도구 > 키워드 도구, '연관키워드 조회 기준' 영역(키워드 / 웹사이트 / 업종 / 시즌 월 / 시즌 테마), [조회하기], [입력값 지우기]
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/1406 ; https://ads.naver.com/help/faq/1640 ; https://ads.naver.com/help/faq/1639
- 코치 연결: 사장님이 넣은 검색어 → 코치 검색어 입력과 같은 자리(코치도 키워드 최대 5개까지 함께 조회)

본문: 키워드 도구는 네이버애즈에서 검색광고 > 도구 > 키워드 도구 메뉴에 있습니다. '키워드' 칸에 한 줄에 하나씩(또는 쉼표로) 최대 5개까지 넣고, 키워드 하나는 1~30자여야 합니다. 키워드 대신 내 계정에 등록된 웹사이트를 골라도 되고, 업종·시즌 월·시즌 테마는 고르지 않아도 됩니다. [조회하기]를 누르면 아래 표에 연관키워드가 나오고, 연관키워드 이름을 누르면 최근 1년 월별 검색수 흐름과 성별·나이대 통계도 볼 수 있어 계절 상품이면 꼭 확인하세요. 5개를 넘기거나 30자를 넘기면 안내·오류가 뜹니다.

## [naver-kw-002] 키워드 도구 표의 숫자들은 무슨 뜻이에요?
- 매체: 네이버 검색광고 | 단계: 키워드 고르기
- 질문 예시: "월간검색수가 뭐야?" / "경쟁정도 높음이면 하지 말아야 해?" / "월평균노출광고수는 뭐야?"
- 화면 단서: '연관키워드 조회 결과' 표의 열: '연관키워드', '월간검색수'(PC / 모바일), '월평균클릭수'(PC / 모바일), '월평균클릭률'(PC / 모바일), '경쟁정도', '월평균노출광고수'
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/1639 ; https://ads.naver.com/help/faq/1640 ; https://github.com/naver/searchad-apidoc/blob/gh-pages/assets/json/ncc-keywordstool.json
- 코치 연결: '월간검색수'(PC+모바일) → 코치 Q1 네이버 배분의 수요 상한, '경쟁정도' → 코치 추천 키워드 고르기

본문: '월간검색수'는 한 달 동안 그 키워드가 검색된 횟수로 PC와 모바일이 따로 나옵니다(API 설명으로는 최근 30일 합계). '월평균클릭수'와 '월평균클릭률'은 그 키워드에 붙은 광고가 한 달 평균 받은 클릭 수와 클릭 비율(%)이고, API 설명으로는 최근 4주 기준입니다. '경쟁정도'는 그 키워드를 두고 광고주끼리 얼마나 경쟁하는지 보여 주는 지수(낮음·중간·높음)이고, '월평균노출광고수'는 그 키워드에 한 달 평균 몇 개의 광고가 보였는지입니다. 스마트스토어 손님은 대부분 모바일로 검색하니 모바일 숫자를 먼저 보세요. 각 열 제목을 누르면 정렬되고, '필터를 입력해 주세요' 칸으로 목록을 좁힐 수 있습니다.

## [naver-kw-003] 검색수에 "< 10"이라고 나오면 뭐예요?
- 매체: 네이버 검색광고 | 단계: 키워드 고르기
- 질문 예시: "< 10 은 0이라는 거야?" / "검색수가 10 미만이면 광고해도 돼?"
- 화면 단서: '월간검색수' 열의 '< 10' 표시
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/1639 ; https://github.com/naver/searchad-apidoc/blob/gh-pages/assets/json/ncc-keywordstool.json
- 코치 연결: 코치는 '< 10'을 5회로 보고 계산(앱의 근사값, 네이버 공식 값 아님) → 코치 Q1 네이버 수요 상한이 아주 작게 나옴

본문: 한 달 검색수가 10회보다 적으면 정확한 숫자 대신 '< 10'으로 표시됩니다. 0이라는 뜻은 아니고 "아주 적다"는 뜻입니다. 이런 키워드만으로는 광고를 켜도 노출 자체가 거의 없으니, 조금 더 넓은 말(예: 상품 종류 이름)로 다시 조회해 검색수가 있는 연관키워드를 찾아보세요. API로 받을 때도 같은 경우 숫자가 아니라 글자로 와서, 우리 코치는 이 값을 5회로 바꿔 더합니다.

## [naver-kw-004] 초보는 어떤 키워드를 골라야 해요?
- 매체: 네이버 검색광고 | 단계: 키워드 고르기
- 질문 예시: "검색량 많은 키워드가 제일 좋은 거 아니야?" / "작은 가게는 어떤 키워드로 시작해?" / "세부 키워드가 뭐야?"
- 화면 단서: '월간검색수', '경쟁정도' 열 정렬, '필터를 입력해 주세요' 입력란
- 확인: △ 공식 문서에서 선별 기준을 찾지 못해 우리 코치 규칙 기준 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/1406 (공식: 상세 데이터를 참고해 키워드를 선별하라는 안내까지만) ; 나머지 기준은 이 앱 코치 규칙(src/engine/naver_source.py `recommend_keywords`)
- 코치 연결: 코치 추천 키워드(월 검색수 300~1만 '세부' 구간 + 경쟁정도 낮음·중간, 입력한 검색어를 포함한 것만)

본문: 네이버 공식 도움말은 월간검색수·월평균클릭수·클릭률을 보고 고르라고만 하고, "몇 회 이상" 같은 기준은 주지 않습니다. 그래서 우리 코치는 예산이 작은 가게라면 큰 단어(예: '원두')보다 상품을 구체적으로 말하는 세부 키워드(예: '디카페인원두1kg')를 먼저 권합니다. 코치 기준은 한 달 검색수 300~1만 회, '경쟁정도'가 낮음이나 중간, 그리고 사장님이 넣은 검색어를 포함한 키워드입니다. 이 기준은 네이버 규칙이 아니라 이 앱의 판단이니, 결과가 나쁘면 바꿔도 됩니다.

## [naver-kw-005] 키워드 도구에서 고른 키워드를 광고그룹에 넣으려면?
- 매체: 네이버 검색광고 | 단계: 키워드 고르기

- 화면 단서: 행의 [+추가], [전체추가], '선택한 키워드 N/100', [지우기], [바로추가] (도움말에 따라 [+바로추가]로도 표기)
- 확인: ✅ 공식 | 확인일: 2026-11-09

- 코치 연결: 코치 추천 키워드 → 여기서 담아 광고그룹에 추가, 입찰가는 그룹 기본 입찰가(코치 기본 입찰가)로 들어감

본문: 결과 표에서 원하는 키워드 줄의 [+추가]를 누르면 오른쪽 '선택한 키워드'에 담깁니다(현재 페이지 전체는 [전체추가]). 한 번에 100개까지 담을 수 있고, 다 담았으면 [바로추가]를 눌러 캠페인과 광고그룹을 고릅니다. 이렇게 넣은 키워드는 그 광고그룹의 기본 입찰가로 등록됩니다. 이 기능은 '파워링크 캠페인'의 광고그룹에만 됩니다.

## [naver-api-001] 키워드 도구 API(/keywordstool)는 어떻게 부르나요?

본문: 키워드 도구 API는 GET /keywordstool이고, 사업자 채널(siteId), 업종(biztpId), 힌트 키워드(hintKeywords), 시즌 테마(event), 월(month) 중 하나 이상을 넣어 조회합니다. hintKeywords는 쉼표로 구분해 최대 5개까지입니다. showDetail=1이면 연관키워드마다 검색수·클릭수·클릭률·경쟁 지수·광고 깊이까지 받고, 0이면 연관키워드와 월 검색수만 받습니다. 공식 공지에 따르면 이 API는 다른 API보다 호출 속도가 1/5~1/6 수준으로 묶여 있고 IP 단위로도 제한되므로, 429(Too Many Requests)가 오면 다른 API보다 5~6배 길게 쉬었다 다시 부르고, 연속 429가 쌓였으면 최소 5분 멈추라고 안내합니다.

본문: 품질지수는 내 광고가 다른 광고보다 검색한 사람의 뜻에 얼마나 맞는지를 7단계 막대로 보여 줍니다(1~2개 낮음, 3~5개 보통, 6~7개 높음). 파워링크는 대신 '광고 연관지수'(키워드와 연결 페이지 내용이 얼마나 맞는지)와 '클릭 기대지수'(소재가 클릭을 얼마나 부를지)를 10점 만점으로 보여 주며, 1~3점은 개선 필요, 4~6점 평균, 7~10점 양호입니다. 이 지수는 최근 60일 안에 노출된 키워드에만, 전날 기준 하루 한 번 갱신됩니다. 쇼핑검색 품질지수는 소재(상품)마다 매겨지니 상품명·이미지를 상품과 맞게 매력적으로 쓰고 상세페이지를 잘 만드는 것이 가장 큰 방법입니다.

## [naver-setup-014] 파워링크 광고 문구(소재)는 어떻게 써요?
- 매체: 네이버 검색광고 | 단계: 소재 만들기
- 질문 예시: "광고 제목 몇 글자까지 돼?" / "소재 등록이 안 돼요(등록 불가)" / "연결 URL은 뭐야?"
- 화면 단서: 광고그룹 [소재] 탭 > [새 소재], 소재 유형 '반응형 소재' / '단일형 소재', '표시 URL', '연결 URL', '키워드 삽입', '미리보기', [저장 후 닫기]
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/1130 ; https://ads.naver.com/help/faq/1024 ; https://ads.naver.com/help/faq/1025
- 코치 연결: 코치 판매가·NT/UTM 꼬리표 링크 → 연결 URL에 붙일 링크

본문: 소재는 검색 결과에 보이는 제목·설명과, 누르면 이동하는 연결 URL로 이뤄집니다. 단일형은 제목(최대 15자)과 설명(20~45자)을 1개씩, 반응형은 제목 3개 이상(최대 15개)·설명 2개 이상(최대 4개)을 넣습니다. 특수문자를 많이 쓰거나, 키워드 삽입을 제목 1회·설명 2회보다 많이 쓰거나, 금칙어를 쓰거나, 설명에 띄어쓰기가 없으면 '등록 불가'가 뜹니다. 키워드를 손님의 질문, 소재를 그 답으로 생각하고 혜택과 다른 가게와의 차이를 사실대로 쓰세요. 소재를 2개 이상 넣으면 성과가 좋은 소재가 더 자주 보이도록 자동 조절됩니다.

## [naver-setup-015] 광고 검토(검수)는 얼마나 걸리고 왜 안 끝나요?
- 매체: 네이버 검색광고 | 단계: 검토
- 질문 예시: "광고 등록했는데 언제 나와?" / "계속 검토 중이야" / "노출 제한이 떴어"
- 화면 단서: 상태 '검토 중' / '노출 가능' / '노출 제한'
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/1466 ; https://ads.naver.com/help/faq/1141 ; https://ads.naver.com/help/faq/1409 ; https://ads.naver.com/help/faq/1469
- 코치 연결: 없음(다만 광고 시작일이 검토만큼 늦어지니 코치의 14일 판단 시작일은 실제 노출일로 잡기)

본문: 등록한 광고는 비즈채널(사이트·쇼핑몰) → 키워드 → 소재 순으로 검토받고, 대부분 영업일 1~2일, 쇼핑검색광고는 보통 1영업일 안에 끝납니다(면밀한 검토가 필요하면 최대 5영업일). 비즈머니 잔액이 0원이면 검토가 시작되지 않고, 비즈채널이 '검토 중'이나 '노출 제한'이면 키워드·소재 검토도 진행되지 않습니다. 광고가 나가려면 광고그룹에 '노출 가능'인 비즈채널·소재·키워드가 각각 1개 이상 있어야 합니다. 파워링크는 비즈채널 URL에 쇼핑몰 메인 주소를, 쇼핑몰 상품형은 글자가 들어가지 않은 상품 이미지를 쓰면 반려를 줄일 수 있습니다. 결과는 메일로도 옵니다.

## [naver-setup-016] 구매(전환)가 보고서에 잡히게 하려면? 성과는 어디서 봐요?
- 매체: 네이버 검색광고 | 단계: 전환 추적 · 보고서
- 질문 예시: "광고로 몇 개 팔렸는지 어떻게 봐?" / "스마트스토어도 전환 스크립트 깔아야 해?" / "전환수가 실제 주문이랑 달라"
- 화면 단서: 도구 > 전환 추적 관리 > 웹사이트 [+ 전환 추적 신청], 상태 '설치 완료', 캠페인 설정의 전환 추적 대상, 성과 보고서 메뉴(광고비 보고서 / 성과 보고서), 지표 '총 전환수', '총 전환매출액', '총 광고수익률(%)'
- 확인: ✅ 공식 | 확인일: 2026-11-09
- 출처: https://ads.naver.com/help/faq/848 ; https://ads.naver.com/help/faq/1649 ; https://ads.naver.com/help/faq/1460 ; https://ads.naver.com/help/faq/1386
- 코치 연결: 리포트의 전환수·전환매출액 → 한 달 뒤 코치 성과 판단 입력값(코치는 광고 리포트 전환을 판매처 통계와 함께 봄)

본문: 전환 추적은 무료이고 도구 > 전환 추적 관리 > 웹사이트에서 [+ 전환 추적 신청]으로 시작합니다. 스마트스토어·브랜드스토어는 스크립트 설치 없이 신청하자마자 '설치 완료'가 되고, 자사몰은 기술 담당자 메일로 오는 안내(보통 1~3일)에 따라 직접 설치하거나 대행 설치를 맡깁니다. 신청 뒤에는 캠페인 설정에서 그 전환 추적 대상을 꼭 골라야 하고, 소재 연결 URL의 도메인이 같아야 하며, 자동으로 붙는 'NaPm=' 파라미터가 리다이렉트로 사라지면 집계가 안 됩니다. 전환 추적 기간은 1~30일로 정할 수 있습니다. 성과는 성과 보고서 메뉴에서 보고, 총 전환수·총 전환매출액·총 광고수익률(전환매출액 ÷ 총비용 × 100)이 '사용중'인 전환 추적 사이트에 대해서만 잡힙니다.
